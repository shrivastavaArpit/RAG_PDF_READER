1. WHAT IS ARTIFICIAL INTELLIGENCE?
Artificial Intelligence (AI) is a field of computer science focused on building systems that can perform tasks that normally require human intelligence, such as understanding language, recognizing images, making predictions, solving problems, and generating content.

2. MACHINE LEARNING
Machine Learning (ML) is a method in which computers learn patterns from data instead of being explicitly programmed for every possible situation.

Main types:
- Supervised Learning: learns from labeled data.
- Unsupervised Learning: finds patterns in unlabeled data.
- Reinforcement Learning: learns through rewards and penalties.

3. DEEP LEARNING
Deep Learning is a subset of Machine Learning that uses neural networks with multiple layers. It is widely used in computer vision, speech recognition, NLP, and Generative AI.

4. NEURAL NETWORKS
A neuron receives inputs, multiplies them by weights, adds a bias, and applies an activation function.

Basic idea:
output = activation(weighted_sum + bias)

Important terms:
- Weight: determines the importance of an input.
- Bias: shifts the output.
- Activation function: introduces non-linearity.
- Forward propagation: calculates a prediction.
- Backpropagation: calculates how parameters contributed to error.
- Gradient descent: updates parameters to reduce loss.

5. NATURAL LANGUAGE PROCESSING
Natural Language Processing (NLP) is the field of AI concerned with understanding and generating human language.

Common tasks:
- Text classification
- Sentiment analysis
- Translation
- Summarization
- Question answering
- Named entity recognition
- Text generation

Important concepts:
- Token: a unit of text processed by a model.
- Tokenization: splitting text into tokens.
- Embedding: numerical representation of text that captures semantic meaning.

6. GENERATIVE AI
Generative AI refers to AI systems that generate new content based on learned patterns.

It can generate text, code, images, audio, and video.

7. LARGE LANGUAGE MODELS
A Large Language Model (LLM) is a neural network trained on large amounts of text to understand and generate language.

LLMs can answer questions, summarize text, generate content, translate, write code, and extract information.

An LLM processes tokens and predicts likely next tokens based on context.

8. TRANSFORMERS
The Transformer is a neural network architecture that became highly important in modern NLP and Generative AI.

Its key idea is attention. Attention allows a model to determine which parts of the input are important when processing a particular token.

Important concepts:
- Self-attention
- Query, Key, Value
- Positional information
- Encoder
- Decoder
- Multi-head attention

9. ATTENTION
Attention helps a model focus on relevant parts of the input. Self-attention calculates relationships between tokens in the same sequence.

10. EMBEDDINGS
An embedding converts text or another object into a numerical vector.

Semantically similar texts tend to have vectors that are close together in embedding space.

Embeddings are used in:
- Semantic search
- Recommendation systems
- RAG
- Document similarity
- Clustering

11. VECTOR DATABASE
A vector database stores and searches numerical vector representations called embeddings.

Examples:
- Chroma
- FAISS
- Pinecone
- Weaviate

A vector database can find documents that are semantically similar to a user's query.

12. RAG – RETRIEVAL-AUGMENTED GENERATION
RAG combines information retrieval with an LLM.

Basic RAG flow:

Documents
    ↓
Document Loading
    ↓
Text Splitting
    ↓
Embeddings
    ↓
Vector Database
    ↓
User Query
    ↓
Query Embedding
    ↓
Similarity Search
    ↓
Relevant Documents
    ↓
LLM
    ↓
Final Answer

The purpose of RAG is to provide an LLM with relevant external information at query time.

Advantages:
- Can use private documents.
- Can use updated information.
- Can reduce dependence on training data.
- Can provide answers grounded in retrieved context.

13. CHUNKING
Large documents are divided into smaller pieces called chunks before creating embeddings.

Chunking helps because smaller pieces can improve retrieval precision and allow relevant sections to be passed to the LLM.

Important parameters:
- Chunk size
- Chunk overlap

14. SIMILARITY SEARCH
Similarity search finds vectors that are close to a query vector.

Common measures:
- Cosine similarity
- Euclidean distance
- Dot product

Cosine similarity is commonly used for comparing embeddings.

15. LANGCHAIN
LangChain is a framework for developing applications powered by language models.

It provides components for:
- Connecting to LLMs
- Prompt management
- Document loading
- Text splitting
- Embeddings
- Vector stores
- Retrievers
- Chains
- Agents

16. LANGGRAPH
LangGraph is used for building stateful, multi-step, graph-based AI workflows and agent-like applications.

A graph contains:
- Nodes: perform tasks.
- Edges: determine what happens next.
- State: stores information between steps.

17. PROMPTS
A prompt is the input or instruction given to an AI model.

A good prompt usually specifies:
- Task
- Context
- Constraints
- Desired output format

Example:
"Summarize the following article in five bullet points using simple English."

18. TEMPERATURE
Temperature controls the randomness of model output.

Lower temperature:
- More predictable
- More consistent
- Useful for factual or structured tasks

Higher temperature:
- More varied
- More creative
- Useful for brainstorming and creative generation

19. TRAINING VS INFERENCE
Training is the process of learning model parameters from data.

Inference is using a trained model to generate a prediction or response.

Simple distinction:
Training = model learns.
Inference = model uses what it learned.

20. FINE-TUNING
Fine-tuning means further training a pretrained model on a specialized dataset.

It can help a model adapt to a particular style, task, or domain.

Fine-tuning is different from RAG:
- RAG provides external information during inference.
- Fine-tuning changes model parameters.

21. RAG VS FINE-TUNING
RAG:
- Adds external knowledge at query time.
- Good for changing or private information.
- Does not normally change model weights.

Fine-tuning:
- Changes model parameters through additional training.
- Good for behavior, style, or specialized task adaptation.
- Requires training data and additional computation.

22. HALLUCINATION
An AI hallucination occurs when a model generates information that sounds plausible but is incorrect, unsupported, or fabricated.

Ways to reduce hallucination:
- Use reliable retrieved context.
- Improve prompts.
- Require evidence or citations.
- Validate important outputs.
